# WO-5 · Canvas page rewrite — single render branch, auto-launch through proxy

**Scope:** `/canvas/page.tsx` collapses to one path: authenticated user lands on `/canvas`, server-side mints (or reuses) a session, page renders `<iframe src={"/canvas-proxy/<sessionId>/"}>`. No buttons, no tier branches, no Free/Pro distinction.

**Reference:** `docs/architecture/canvas-v2.md` decision 2, build plan step 10.

## Files

- `app/canvas/page.tsx` — full rewrite
- `components/CanvasBridge.tsx` — keep file (still mediates active-project + Queue intercept for the legacy free path) but DROP the witness handlers (now server-side). Update comment header to reflect.
- `app/api/canvas/session/route.ts` — keep but minimal: validate Stripe customer present (WO-6 adds the PaymentIntent), look up active machine for user, lazy-create Modal container if needed, return `{ sessionId, proxyUrl: "/canvas-proxy/<sessionId>/" }`. POST is idempotent within window.
- `lib/canvas/session.ts` — drop the HMAC token concept; sessionId is opaque DB id only. Move token utilities into deprecated `lib/canvas/session.legacy.ts` or delete.

## Page shape

```tsx
export default async function CanvasPage() {
  const session = await auth();
  if (!session?.user?.id) redirect('/sign-in?next=/canvas');

  // mint or reuse
  const { sessionId } = await mintOrReuseCanvasSession(session.user.id);

  return (
    <main className="canvas-shell">
      <iframe src={`/canvas-proxy/${sessionId}/`} className="canvas-iframe" />
      <CanvasBridge iframeId="canvas-iframe" activeProjectId={...} />
      <CanvasSessionHUD sessionId={sessionId} /> {/* shows machine + elapsed cost (WO-6) */}
    </main>
  );
}
```

## Verify

- `/canvas` while signed in → iframe loads immediately, no Launch button visible
- `/canvas` while signed out → redirect to sign-in
- View source: `iframe src` is `/canvas-proxy/<id>/`, NOT a Modal URL
- ComfyUI loads inside iframe; click "Queue Prompt" → workflow runs on Modal; output appears
- DB: `canvas_sessions` row created on first visit, reused on subsequent visits within window
